# Dayflow

React application focused on async todo flows, derived state, selectors and frontend architecture.

## Stack
- React
- JavaScript
- Vite
- CSS
- Vitest

## Features
- async complete flow
- immutable updates
- derived state selectors
- section filtering
- loading states
- reusable components

## Architecture
TodoFlow acts as a container component:
- API calls
- state updates
- selectors
- async flows

Presentation components:
- TodoSection
- TodoItem
- Footer
